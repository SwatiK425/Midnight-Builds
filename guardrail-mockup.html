What It Catches

In-Scope Attack Categories

🎭

Jailbreaks

Roleplay, encoding, hypothetical framing, authority impersonation, token smuggling — anything that tries to bypass the model's safety alignment.

💉

Prompt Injections

Instruction override, context stuffing, tool hijacking, data exfiltration via tool calls — malicious instructions hidden in user input.

📤

Data Exfiltration

Training data extraction, PII/PCI/PHI disclosure, system prompt leakage, chain-of-thought dumping — requests for protected data.

🔗

Unauthorized Intent Combos

Disclosure+Retrieval, Jailbreak+Role, Role+Retrieval, Retrieval+Target, Unfiltered+Retrieval — dangerous intent combinations.
